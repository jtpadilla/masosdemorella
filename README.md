# Masos de Morella. Vida i costums en la Dena dels Llivis

Edició digital de recuperació del llibre de **Francisca Julian i Querol**, publicat com *Masies de Morella* per
Publicacions de la Universitat Jaume I (2006) i revisat per l'autora el 2016 amb el títol *Masos de Morella*. No en queda
cap exemplar localitzable. Esta edició reprodueix la revisió de 2016 a partir del PDF i dels originals que conservava la
família (`source/`): text (`content/`, Markdown) i fotografies (`assets/images/`), i el lloc web:

**https://jtpadilla.github.io/masosdemorella/**

- `source/` — els originals: PDF de 2016, document de Word, fotografies, PDF de 2006 i escaneig de l'edició impresa.
- `content/` — el text del llibre, un fitxer per capítol (masters recuperats).
- `assets/images/` — les 30 fotografies del llibre (26 del PDF, 4 aportades per la família) i les il·lustracions afegides per esta edició (`ed-*.svg`).
- `extract/` — extracció reproduïble del PDF, conversió a Markdown i verificació; generadors de mapes.
- `site/` — el lloc web (Astro); es publica a GitHub Pages en cada push a `main`.
- `NOTES.md` — decisions editorials i tot el que s'ha trobat en l'original. `TODO.md` — tasques pendents.
